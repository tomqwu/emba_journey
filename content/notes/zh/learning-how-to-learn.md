## 从学习目标出发

不存在对所有目标都最好的框架。这个网站组合了帮助记忆、理解和应用的方法。学习流程是网站的设计选择，不是经过验证的 EMBA 干预方案。

## 证据支持什么

| 目标 | 方法与证据 | 网站中的应用 |
| --- | --- | --- |
| 延迟后仍能记住 | Dunlosky 综述将练习测试与分散学习评为高效用方法。[出版方摘要](https://www.psychologicalscience.org/publications/journals/pspi/learning-techniques.html)。 | 先回答，再看反馈，并在之后再次练习。 |
| 形成概念回忆 | Karpicke 与 Blunt 的科学文本实验发现，提取练习优于带着材料制作概念图。这不表示图示无用，也不证明能改善高管业绩。[论文第772–775页](https://learninglab.psych.purdue.edu/downloads/2011/2011_Karpicke_Blunt_Science.pdf)。 | 练习题包含解释与新情境，不只是背定义。 |
| 解释关系 | Chi 等研究了对生物学文本的引导式解释；中学生小样本限制了对 EMBA 的直接推广。[论文摘要与讨论](https://education.asu.edu/sites/g/files/litvpz656/files/lcl/chideleeuwchiulavancher_3.pdf)。 | 解释一个概念为什么有效，以及何时可能失效。 |
| 应用到工作 | Kolb 的经历、反思、概念化和实验循环提供组织思路，并不是本网站复习间隔的证据。[作者指南引言及第一节](https://learningfromexperience.com/books/8-things-to-know-about-the-experiential-learning-cycle.pdf)。 | 记录真实情境、形成解释、尝试改变，再观察结果。 |

2022 年的间隔与提取练习综述讨论了保持与迁移。这次只获取了公开摘要及元数据，没有审阅受许可限制的全文。[综述](https://www.nature.com/articles/s44159-022-00089-1)。

## 学习循环

```concept-map
title: 阅读、回忆、解释、应用，再回来复习
steps:
  - label: 收录与理解
    detail: 阅读有来源的笔记，并了解其局限。
  - label: 回忆与比较
    detail: 先凭记忆回答，再与参考答案比较。
  - label: 解释与实验
    detail: 将概念连接到真实决策，尝试一个小改变。
  - label: 回顾与修正
    detail: 间隔复习、比较结果，并调整解释。
caption: 这是所选方法的实用组合，不是经过独立验证的课程。
```

## 一次简短的练习

打开导航栏中的“练习”。读题后凭记忆作答，可以书写或在心里回答。查看参考答案，与自己的尝试比较，再诚实自评。参考答案是作者整理的提示，不是自动评分系统。

在工作反思区中，分别记录发生了什么、观察到什么、自己的解释、预期以及实际结果。未知的内容留空，不要编造结果。比较国家文化与组织文化题目，练习辨别正确的分析层次。

## 复习日期与进度

初次评分后，“需要再试一次”安排在1天后，“部分回忆起来”安排在3天后，“能清楚回忆”安排在7天后。之后继续清楚回忆，则延长到14、30、60天。这些间隔是透明的产品规则，不是科学优化的处方，也不预测你的记忆。日期使用多伦多时间，随时可以选择“全部练习题”。

新题会自动加入队列。任一语言的题目或答案发生变化时，其版本随之改变，题目重新成为待复习状态。中英文共享进度。

评分时保存回答，点击“保存反思”保存反思。数据只留在当前浏览器，不会同步到 GitHub 或其他设备。可以导出 Markdown 保留副本；保存前关闭页面可能丢失草稿。

## 这些功能不能证明什么

自评分不是客观掌握程度，完成题目也不证明业务成效。需要通过真实决策与结果检验迁移。这个设计没有经过 EMBA 对照组评估。图示、标签和笔记组织帮助导航与解释，但不能替代提取练习。

## 待回顾的问题

- 延迟一段时间后，我还会犯哪些错误？
- 不使用原来的例子，我能解释概念吗？
- 工作中的小实验改变了可观察结果吗？
- 这份材料是否需要更短的复习间隔？

```learning-practice
objective: 根据记忆、理解和应用目标，选择合适的学习活动。
application: 选择一个工作中需要的概念：描述情境、解释概念、预测一个小改变的效果，并记录实际观察。
questions:
  - id: retrieval-versus-reading
    kind: recall
    prompt: 这个网站优先用哪两种方法帮助长期保持知识？
    answer: 提取练习与间隔复习：不看笔记尝试回忆，对照反馈，并在之后再练习。打开或重读笔记不等于提取知识。
  - id: explain-and-transfer
    kind: explain
    prompt: 为什么回忆、解释和工作实验是不同的活动？
    answer: 回忆重建知识，解释探究关系与边界，工作实验在实际情境中检验解释。较高的自评分不能证明业务成效。
  - id: experiment-loop
    kind: transfer
    prompt: 如何把一个 EMBA 概念转化为工作中的小实验？
    answer: 找到真实经历、记录观察、形成暂定解释，预测一个小改变的效果，再比较实际结果。不要编造证据，也不要把所有变化都归因于这个概念。
```
