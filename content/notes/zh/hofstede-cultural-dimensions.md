## 核心要点

霍夫斯泰德的框架提供了一套讨论不同社会的语言。可以用它提出关于行为预期的问题，再调查实际团队或业务情境。国家层面的模式不能证明某个具体的人如何思考或行动。

用户提供的网站介绍了荷兰社会心理学家盖尔特·霍夫斯泰德（Geert Hofstede，1928–2020）以及格特·扬·霍夫斯泰德（Gert Jan Hofstede）的工作。本笔记聚焦国家文化框架。[网站入口](https://geerthofstede.com/)。

## 这里的文化指什么

文化指通过学习形成、由群体共享的社会生活预期。网站将这种共同背景与个人性格区分开来，其范围包括日常互动，而不只是艺术意义上的文化。[来源：文化的定义](https://geerthofstede.com/culture-geert-hofstede-gert-jan-hofstede/definition-culture/)。

## 六个文化维度

以下是对网站解释的简要转述，括号保留原有术语。

| 维度 | 探索的问题 |
| --- | --- |
| 个人主义／集体主义（Individualism / Collectivism） | 个人独立性与相互依赖的社会群体成员身份。 |
| 权力距离（Power Distance） | 权力较小的成员对权力分配不平等的接受与预期。 |
| 男性化／女性化（Masculinity / Femininity） | 社会对性别角色、强硬、获胜和同情他人的预期；并非个体性别或性格。 |
| 不确定性规避（Uncertainty Avoidance） | 对模糊性和未知的反应；不同于风险规避。 |
| 长期／短期导向（Long-term / Short-term Orientation） | 为变化做准备与适应，或将既有传统作为道德参照。 |
| 放纵／克制（Indulgence / Restraint） | 享受生活的自由，或对义务与限制的强调。 |

网站用大致 0–100 的量表进行比较。它把国家地图描述为粗略模式，指出同一国家内部存在明显差异，并承认还可以构建其他维度。[来源：六维模型的地图与维度说明](https://geerthofstede.com/culture-geert-hofstede-gert-jan-hofstede/6d-model-of-national-culture/)。

## 分析层次很重要

网站的多层次讨论区分了个体、群体以及人类共有属性。**学习启示：** 不要用国家平均值替代对个人行为或组织日常实践的观察。[来源：分析层次](https://geerthofstede.com/research-and-vsm/levels-of-analysis/)。

## 应用：跨国项目团队

*以下是假设案例与助手的分析，不是学习者提供的个人经历。*

项目经理发现，一些同事公开质疑提案，另一些同事私下提出担忧。不要直接将这些行为归因于国籍，可以先问：

- 谁应该做出决策？大家怎样才能安全地表达不同意见？
- 哪些决策需要更多解释或更明确的预期？
- 团队如何理解个人负责与集体责任？

尝试具体改进：会前收集书面意见、明确决策责任，并商定如何沟通不确定性。随后比较实际参与度和交付表现。文化只是可能的解释之一，也要考虑角色、激励、语言和团队历史。
