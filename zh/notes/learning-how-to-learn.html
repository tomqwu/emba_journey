从学习目标出发

不存在对所有目标都最好的框架。这个网站组合了帮助记忆、理解和应用的方法。学习流程是网站的设计选择，不是经过验证的 EMBA 干预方案。

学习循环

一次简短的练习

打开导航栏中的“练习”。读题后凭记忆作答，可以书写或在心里回答。查看参考答案，与自己的尝试比较，再诚实自评。参考答案是作者整理的提示，不是自动评分系统。

在工作反思区中，分别记录发生了什么、观察到什么、自己的解释、预期以及实际结果。未知的内容留空，不要编造结果。比较国家文化与组织文化题目，练习辨别正确的分析层次。

复习日期与进度

初次评分后，“需要再试一次”安排在1天后，“部分回忆起来”安排在3天后，“能清楚回忆”安排在7天后。之后继续清楚回忆，则延长到14、30、60天。这些间隔是透明的产品规则，不是科学优化的处方，也不预测你的记忆。日期使用多伦多时间，随时可以选择“全部练习题”。

新题会自动加入队列。任一语言的题目或答案发生变化时，其版本随之改变，题目重新成为待复习状态。中英文共享进度。

评分时保存回答，点击“保存反思”保存反思。数据只留在当前浏览器，不会同步到 GitHub 或其他设备。可以导出 Markdown 保留副本；保存前关闭页面可能丢失草稿。

这些功能不能证明什么

自评分不是客观掌握程度，完成题目也不证明业务成效。需要通过真实决策与结果检验迁移。这个设计没有经过 EMBA 对照组评估。图示、标签和笔记组织帮助导航与解释，但不能替代提取练习。

待回顾的问题

  • 延迟一段时间后，我还会犯哪些错误？
  • 不使用原来的例子，我能解释概念吗？
  • 工作中的小实验改变了可观察结果吗？
  • 这份材料是否需要更短的复习间隔？
