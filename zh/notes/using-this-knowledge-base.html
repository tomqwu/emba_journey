从材料到知识

将幻灯片、关键词、文章、链接或零散笔记交给收录助手。每份材料都会被整理成有来源依据的 Markdown 笔记，归入学科，并与相关概念建立联系。

本指南介绍知识库的使用方式，不代表已完成任何课程。

一篇好笔记回答四个问题

  1. 核心观点是什么？
  2. 哪些证据和假设支持它？
  3. 可以在哪里应用？
  4. 哪些问题仍未解决？

发现知识关联

按学科浏览某一领域，通过搜索标题、标签、课程名称和正文找到具体概念。关联笔记帮助你连接不同课程中的框架。每篇笔记有一个主要学科分类，也可以有多个主题标签。

保持记录可信

来源摘要与个人反思分开呈现。缺失的信息记录为待解问题。没有上下文的关键词保持暂定状态，直到有足够证据解释其含义。

收录下一份学习材料

在这个仓库的 Codex 对话中，说“把这份材料收录到我的 EMBA 知识库”，并附上或粘贴内容。也可以补充课程、分类或希望解决的业务问题。仓库指令会引导助手使用收录技能。

所有学习文档均保存为 Markdown。构建和验证在本地完成后再发布网站。草稿不会显示在网站上，但提交到这个公开仓库的任何文件都可以被公开访问。

选择语言

点击页面顶部的 EN / 中文，切换整个知识库的语言。中英文笔记使用相同的主题标签标识和关联关系，各自拥有完整正文。浏览器会保存你通过语言按钮选择的偏好。
